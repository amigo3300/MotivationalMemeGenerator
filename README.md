# Meme Generator

A tool that creates memes by combining a random (or chosen) image with a
quote and its author. It can be run from the command line or as a Flask
web app. Quotes can be read from CSV, DOCX, PDF, and TXT files.

## Setup

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

This installs: `Pillow`, `pandas`, `python-docx`, `Flask`, and `requests`.

### 2. Install pdftotext (required for PDF quotes)

```bash
brew install poppler        # macOS
sudo apt-get install poppler-utils   # Ubuntu/Debian
```

### 3. Check the project folders

- `_data/photos/` - source images
- `_data/DogQuotes/` - quote files (CSV, DOCX, PDF, TXT)
- `fonts/` - font files used to draw text
- `tmp/` - generated memes and temporary files
- `static/` - memes generated by the web app
- `templates/` - HTML templates (`meme.html`, `meme_form.html`)

## Running the program

### Command line

```bash
python3 main.py                                      # random image and quote
python3 main.py --path ./_data/photos/dog/xander_1.jpg --body "Quote text" --author "Name"
```

- With no arguments, a random dog photo and a random quote from the quote
  files are used.
- If `--body` is given, `--author` is required.
- The generated meme is saved in `./tmp` and its path is printed.

### Web app

```bash
python3 app.py
```

or

```bash
flask --app app.py run
```

Then open `http://127.0.0.1:5000` in a browser.

| Route     | Method | Description                                                                    |
|-----------|--------|--------------------------------------------------------------------------------|
| `/`       | GET    | Shows a meme made from a random image and a random quote.                      |
| `/create` | GET    | Shows a form for entering an image URL, a quote, and an author.                |
| `/create` | POST   | Downloads the image from the submitted URL, creates the meme, and displays it. |

Memes created by the web app are saved in `./static`. If the image URL
cannot be downloaded, or does not point to a valid image, the app responds
with a 400 error and a short message.

## Modules

### QuoteEngine

Reads quotes from files and returns them as `Quote` objects.

| Class               | Responsibility                                                              |
|---------------------|-----------------------------------------------------------------------------|
| `Quote`             | Holds a quote's `body` and `author`.                                        |
| `IngestorInterface` | Abstract base class: defines `can_ingest()` and `parse()`.                  |
| `CSVIngestor`       | Parses CSV files with `body` and `author` columns. Uses `pandas`.           |
| `DocxIngestor`      | Parses DOCX files with `body - author` per line. Uses `python-docx`.        |
| `PDFIngestor`       | Parses PDF files by converting them with the `pdftotext` command-line tool. |
| `TXTIngestor`       | Parses TXT files with `body - author` per line.                             |
| `Ingestor`          | Picks the right ingestor for a file based on its extension.                 |

```python
from QuoteEngine.Ingestor import Ingestor

quotes = Ingestor.parse('./_data/DogQuotes/DogQuotesCSV.csv')
print(quotes[0].body, quotes[0].author)
```

### MemeEngine

Draws a quote and author onto an image.

- Resizes the image to a given width, keeping its aspect ratio.
- Places the quote at a random position inside the image, with the author
  on the line below.
- Depends on `Pillow` and the fonts in `fonts/`.

```python
from MemeEngine.MemeEngine import MemeEngine

meme = MemeEngine('./tmp')
path = meme.make_meme('./image.jpg', 'Quote text', 'Author name')
```

### app.py

Flask web app. At startup it loads all quotes with `Ingestor` and finds all
images under `_data/photos/dog/`. Uses `MemeEngine` to create memes, and
`requests` to download images submitted through the form.

## Error handling

Ingestors raise descriptive exceptions for unsupported file types, missing
or invalid files, and lines that are not in `body - author` format.
